# Рупор — проверка перед выпуском

## Автоматические проверки

Из корня проекта (Python-окружение `.venv` и `npm install` в `ui` — см.
[README.ru.md, «Сборка из исходников»](../README.ru.md#сборка-из-исходников)):

```bat
.venv\Scripts\python -m pytest -q
.venv\Scripts\python -m mypy core/rupor
cd ui && npm run typecheck && npm run build && npm run check:i18n && cd ..
cd ui\src-tauri && cargo clippy --all-targets -- -D warnings && cargo test && cd ..\..
```

Тесты ядра не нажимают клавиш и не трогают буфер обмена и звук пользователя: вставка и активные
окна подменены, настоящий буфер проверяется в отдельном процессе со своей window station
(`tests/test_clipboard.py` → `tests/_clip_isolated.py`), приглушение звука — на собственной
аудиосессии теста (`tests/test_duck.py`), конец сеанса Windows — сообщениями собственному
скрытому окну (`tests/test_duck_engine.py`). Если нужного ресурса нет (window station, устройство
вывода звука), тест пропускается. Настройки, база и журналы в тестах лежат во временных папках;
для полной изоляции можно запустить pytest с `APPDATA` и `LOCALAPPDATA`, указывающими во
временную папку.

Переводы проверяются там же: `npm run check:i18n` — паритет ключей `ui/src/i18n/ru.json` и
`en.json`, формы множественного числа, одинаковые подстановки, нет кириллицы в `en.json` и в
коде интерфейса; `tests/test_i18n.py` — то же для каталогов ядра `core/rupor/locales/*.json`
плюс смена языка на лету через настоящий WS-сервер; `cargo test` — одинаковые поля и
подстановки у русских и английских строк оболочки (`src/i18n.rs`) и ключи `update_tray.labels`.

Дополнительно:

- `cargo test -- --ignored real_core_smoke` (в `ui\src-tauri`) — оболочка с настоящим ядром из
  `.venv` (`--sidecar --no-hook --no-mutex`);
- `.venv\Scripts\python tools\ws_smoke.py` — дымовой тест ядра по WebSocket (в том числе смена
  языка на лету);
- `npm run check:contract -- --port <порт> --token <токен> --quit` (в `ui`) — сверка протокола
  ядра с типами интерфейса, в том числе смена `language` и `dictation_language`, папка модели
  (`model_dir`, поля `setup_status`, `model_recommend`, `model_dir_set`; смена папки — только на
  ядре первого запуска без модели, перенос не запускается) (см. [ui/README.md](../ui/README.md));
- `.venv\Scripts\python packaging\verify_core.py [путь\к\rupor-core.exe]` — самопроверка
  собранного ядра (её же выполняет `build.cmd`; требует «локализация: ok»).

## Ручная приёмка

- [ ] «Сниппеты»: при пустом списке «Экспорт» недоступен, «Импорт» доступен;
      открытие и отмена создания сниппета не включают экспорт. После сохранения первого
      сниппета экспорт доступен; после удаления последнего снова недоступен, «Вернуть»
      включает его. Поиск без результатов при непустом списке не отключает экспорт.
- [ ] «Сниппеты → Добавить сниппет»: у карточки стандартный тонкий бордер без цветной
      внешней обводки и обрезанного свечения по краям; фокус поля ввода остаётся видимым.
      Проверить обе кнопки добавления, отмену через Esc и сохранение через Ctrl+Enter,
      светлую и тёмную темы, RU/EN.
- [ ] «Словарь → Термины»: при пустом списке «Экспорт» недоступен, «Импорт» доступен;
      создание черновика не включает экспорт, сохранение первого термина включает,
      удаление последнего выключает, «Вернуть» включает снова. Поиск без результатов
      при непустом словаре не отключает экспорт. Карточка «Добавить термин» имеет
      стандартный тонкий бордер без цветного внешнего свечения; фокус полей виден.
- [ ] Фокус с клавиатуры: последние диктовки на главной и варианты в «Правила приложений →
      Добавить приложение» имеют видимый замкнутый контур внутри границ строки.
      При ручном вводе API-ключа в настройках и мастере подсветка поля не обрезается
      сверху и по бокам; кнопка сохранения также имеет видимый фокус.
- [ ] Мастер первого запуска: выбор языка, микрофон, загрузка модели и CUDA, тест
      распознавания, ключ ИИ (и пропуск шага с ключом)
- [ ] Мастер, шаг «Видеокарта и модель»: рекомендация соответствует компьютеру (с видеокартой
      NVIDIA от 4 ГБ — `large-v3-turbo`; на машине без видеокарты — `small` или `base`), причина
      на языке интерфейса, у моделей размеры как на Hugging Face; без сети — шаг открывается за
      ≈5 с с запасными размерами. Выбор другой модели меняет строку загрузки. «Куда скачать
      модель» → «Обзор…» (системный диалог), папка с кириллицей и пробелами — модель качается
      туда (`models--…` внутри), после мастера диктовка работает с этой папкой
- [ ] Папка модели («Настройки → Диктовка → Папка модели»), модель скачана: новая папка на
      **том же** диске → «Перенести» — мгновенно, тост «Модель перенесена в …», старой копии нет;
      на **другом** диске — прогресс «Переношу модель …: N из M МБ», во время переноса диктовка
      работает; после — `refs\main` и `snapshots` на месте, перезапуск Рупора берёт модель из
      новой папки без сети. «Не переносить» — модель качается в новую папку, прежняя распознаёт
      до готовности. «По умолчанию» возвращает кэш Hugging Face. Перенос на диск, где не хватает
      места, — ошибка до начала копирования, настройки прежние. Относительный путь — ошибка
      «Папка модели: нужен полный путь…»
- [ ] Блокнот: русская фраза с английскими терминами; словарь и сниппет срабатывают
- [ ] Браузер (поле ввода), Telegram (стиль «Сообщение в мессенджер»), Cursor/VS Code (стиль
      «Для кода»)
- [ ] `mstsc` с включённым и **отключённым** буфером (печать клавишами), полноэкранный RDP;
      многострочный текст (сниппет, список от ИИ) — переносы строк на месте
- [ ] Рассылка в 2+ RDP-сессии (Ctrl+Win+Shift), фокус возвращается
- [ ] «Без рук»: двойное нажатие → говорить → нажатие; Esc отменяет запись; Ctrl+Win+D и
      Ctrl+Win+стрелки работают как обычно и не запускают диктовку
- [ ] Щелчок по пилюле: запись «без рук», второй щелчок — вставка в прежнее окно
- [ ] ИИ «Ждать очистку» и «Сначала сырой»; отключите сеть — вставится текст без обработки
- [ ] Командный режим: выделить текст → Ctrl+Win+Alt → «переведи на английский»
- [ ] «Вставить последнее» и повторная вставка из истории попадают в последнее окно
- [ ] Окно от администратора (например, `regedit`): появляется предупреждение с перезапуском
- [ ] RDP, длинный многострочный текст: зажать Ctrl+Win для следующей фразы, пока печатается
      предыдущая, — печать ждёт отпускания, переносы строк не становятся Ctrl+Enter
- [ ] Вставка через буфер: журнал Win+V не пополняется диктовками; после вставки буфер прежний
- [ ] «Сначала сырой»: щелчок мышью в другое место до ответа ИИ — замена отменяется, текст цел
- [ ] Звук во время записи: включить музыку, зажать Ctrl+Win — после звука начала музыка тише,
      отпустить — как была; «без рук» и щелчок по пилюле — так же; «Выключать» — беззвук;
      во время записи поднять громкость плеера в микшере — после записи она остаётся вашей;
      запустить видео во время записи — через полсекунды тоже тише; RDP со звуком — тише;
      снять процесс ядра во время записи — после перезапуска громкость вернулась
- [ ] Обучение словаря: в Блокноте и Telegram продиктовать «проверь метабейс», исправить на
      «Metabase» и щёлкнуть в другое окно (в Telegram — отправить Enter) → уведомление
      «В словарь добавлено…» (держится 12 с), «Отменить» убирает термин; «завтра» →
      «послезавтра» — ничего; RDP-окно — ничего. Словарь → «Недавно добавлено»: выученный
      термин с пометкой «добавил Рупор» и временем, «Отменить» в строке убирает его из словаря
- [ ] Установщик: установка поверх прежней версии сохраняет настройки и историю; удаление с
      галочкой «Удалить данные приложения» стирает `%APPDATA%\Rupor`, `%LOCALAPPDATA%\Rupor` и
      ключи в диспетчере учётных данных

### Язык (русский и английский)

- [ ] «Настройки → Общие → Язык интерфейса»: English → Русский → Системный — главное окно,
      пилюля, меню трея и подсказка значка, заголовки окон, названия стилей, уведомления и
      ошибки ядра меняются сразу, без перезапуска; «Системный» — как язык Windows
- [ ] Первый запуск с чистым `%APPDATA%\Rupor` (лучше в английской Windows): мастер начинается
      с выбора языка, на карточке языка Windows — отметка «Язык Windows» / “Windows language”;
      English — все шаги мастера и трей по-английски
- [ ] Трей сразу после запуска, до подключения окна, — на языке из `settings.json` (для
      «Системного» — на языке Windows)
- [ ] «Язык диктовки: Авто» при английском интерфейсе: английская фраза — английский текст,
      русская — по-русски; при русском интерфейсе — так же. «Русский» / «English» — всегда
      этот язык
- [ ] ИИ-очистка английской фразы с паразитами и самопоправкой («um so basically… no wait…») —
      текст очищен по-английски и не переведён; русская фраза — как раньше; командный режим
      при английском интерфейсе («make it shorter»)
- [ ] Обучение словаря при английском интерфейсе: уведомление “Added to dictionary: …” с
      кнопкой Undo
- [ ] Установщик: окно выбора языка (English / Russian), страницы и сообщения хуков на
      выбранном языке, название в мастере и в «Установленных приложениях» — «Rupor» / «Рупор»;
      обновление поверх прежней версии оставляет папку `%LOCALAPPDATA%\Рупор` и автозапуск;
      удаление на английском — те же галочки и сообщения

## Скриншоты для README

`docs/screenshots/en/*.png` и `docs/screenshots/ru/*.png` снимаются в демо-режиме со статической
сборки, все данные на них вымышлены: `cd ui && npm run build && npm run preview` (порт 1421),
headless Chrome, светлая тема, окно шириной 1200 px, масштаб 1:

- `home.png` — `http://localhost:1421/?mock=1&lang=<en|ru>#/home` (высота 822);
- `history.png`, `dictionary.png`, `settings.png` — `#/history`, `#/dictionary`,
  `#/settings/dictation` (высота 780);
- `language.png` — `#/settings/general`, верхние 440 px (блок «Язык»);
- `pill.png` — шесть состояний `pill.html?mock=1&lang=<en|ru>` (демо-цикл: запись, «Вставлено»,
  «без рук», ИИ; `&demo=0&scene=broadcast` — рассылка; `&demo=0&learn=1` — уведомление
  словаря), снятых с прозрачным фоном в масштабе 2 и собранных в сетку 2×3 с подписями на
  языке скриншота.

Кнопку «Демо: имитация диктовки» / “Demo: simulate dictation” в меню перед снимком скрывают, а
`localStorage` страницы очищают, чтобы на снимок не попали следы прошлых запусков: тема и акцент
(`rupor.theme` — по ним рисуется первый кадр до ответа демо-ядра) и запомненный язык Windows
(`rupor.systemLocale` — подпись «Системный · …» и карточка «Язык Windows» в мастере, когда язык
выбран явно). Язык интерфейса от этого не зависит: `?lang` всегда важнее кэша `rupor.locale`.

## Публикация релиза

1. Поднять версию (одну и ту же) в `ui/src-tauri/tauri.conf.json`, `ui/src-tauri/Cargo.toml`,
   `ui/package.json` и `pyproject.toml`; если менялись зависимости — пересобрать перечень в
   `THIRD_PARTY_NOTICES.md` и `THIRD_PARTY_NOTICES.ru.md` (порядок — в конце этих файлов).
2. Все автоматические проверки и ручная приёмка выше, затем `build.cmd`.
3. Переименовать установщик: `Рупор_<версия>_x64-setup.exe` → `Rupor_<версия>_x64-setup.exe`
   и выкладывать в GitHub Releases под этим именем. GitHub переименовывает файлы релиза, в
   именах которых есть символы вне ASCII, и файл с кириллицей получил бы искажённое имя; README
   (раздел «Установка» / “Installation”) ссылается именно на `Rupor_<версия>_x64-setup.exe`.
   Сам установщик от имени файла не зависит: папка установки и ярлыки по-прежнему «Рупор».
4. После загрузки проверить имя файла на странице релиза и скачать его ещё раз: размер
   (≈ 55 МБ) и SHA-256 совпадают с локальным файлом.
