## Баги

Известные ограничения и места, где поведение расходится с ожидаемым.

- **Обучение словаря на правках не работает в RDP-сессиях.** UI Automation не видит поле внутри
  `mstsc` (`docs/ROADMAP.md`, п. 1).
- **Командный режим не работает в терминалах и в RDP без общего буфера обмена**
  (README, «Command mode»).
- **Вставка через буфер ломает «вырезать» в Excel и фигуры Office.** Диапазон, вырезанный
  Ctrl+X, после диктовки вставится как копия, фигуры Office не восстанавливаются; обход —
  правило «Нажатия клавиш» для приложения (README, «Clipboard limitations»).
- **Рассылка в mRemoteNG и RDCMan уходит только в активную вкладку.** Все вкладки — одно окно
  (README, «Broadcast to RDP»).
- **Длинный русский контекст окна тянет английские термины в кириллицу.** На замере a16:
  «Python» / «pytest» → «Пайтоне» / «Пайтест»; в a05 «Python» → «Пайтоне» и без контекста
  (`docs/ROADMAP.md`, п. 4, замер `wer_bench`).
- **Установщик без подписи издателя.** SmartScreen показывает «Неизвестный издатель», браузер
  предупреждает о редком файле (README, «Installation»).

## Идеи

- **Автотранскрибер.** Перетащил аудио- или видеофайл (созвон, голосовое из Telegram) → текст
  с таймкодами в историю и в файл; та же локальная модель, без интернета.
- **Автопереводчик при диктовке.** Говоришь по-русски — вставляется по-английски (и обратно):
  отдельная клавиша или стиль ИИ / правило приложения «переводить на …». Сейчас перевод есть
  только командой над выделенным текстом.
- **Обучение словаря в RDP** без UI Automation: сравнивать вставленный текст с тем, что потом
  ушло через буфер или повторной диктовкой.
- **Рассылка во все вкладки mRemoteNG / RDCMan** по очереди, с возвратом на исходную вкладку.
- **Подпись установщика** (например, бесплатная подпись для open-source через SignPath), чтобы
  убрать предупреждение SmartScreen.
- **Командный режим в терминалах:** читать выделение через UIA / консольный API вместо буфера.
